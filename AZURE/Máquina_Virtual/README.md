# ☁️ Máquina Virtual no Azure

Uma **Máquina Virtual (VM)** no Azure é um recurso de computação que simula um computador físico dentro da nuvem da Microsoft. Com ela, você pode rodar sistemas operacionais e aplicativos como se estivesse em um computador real, mas com os benefícios da nuvem.

## 🛠️ Funcionalidades principais

- **Customização completa**: escolha o sistema operacional (Windows, Linux), a quantidade de memória RAM, processadores e armazenamento.
- **Escalabilidade**: é possível aumentar ou diminuir os recursos conforme a necessidade.
- **Acesso remoto**: conexão via RDP (Windows) ou SSH (Linux) para gerenciar sua VM de qualquer lugar.
- **Segurança integrada**: inclui firewall, controle de acesso, criptografia de dados, entre outros.

## 💡 Casos de uso

- Ambiente de **desenvolvimento e testes**.
- Hospedagem de **aplicações web ou APIs**.
- Execução de **bancos de dados** ou **softwares corporativos**.
- Simulações, processamento de dados e **projetos acadêmicos**.

## 💰 Custo

- O valor depende da **configuração da VM** (CPU, RAM, tipo de disco).
- Pagamento é feito por **uso (por hora ou por segundo)**.
- Existe um **plano gratuito** com recursos limitados, ideal para testes e aprendizado.

## 🔒 Segurança

- VMs são isoladas umas das outras.
- Suporte a **rede virtual privada (VNet)**, **NSG (Network Security Groups)** e **firewalls**.
- Opções de **backup, monitoramento e atualizações automáticas**.

---

As máquinas virtuais no Azure são uma ótima opção para quem precisa de poder computacional sem investir em hardware físico, com total flexibilidade e controle.
