# Microsoft Search e Azure Storage

Explorei dois serviços da Microsoft voltados para a busca de informações e armazenamento em nuvem: o **Microsoft Search** e o **Azure Storage**. Nesta experiência, testei apenas **algumas funcionalidades básicas** de cada serviço, com o objetivo de compreender seu funcionamento na prática.

## Microsoft Search

O **Microsoft Search** é uma ferramenta de busca inteligente integrada aos serviços da Microsoft, como Outlook, OneDrive, SharePoint e Teams. Ele permite localizar rapidamente arquivos, e-mails, pessoas e outras informações relevantes dentro de uma organização.

### Funcionalidades do Microsoft Search

- **Busca Unificada**: Pesquisa em diversos serviços Microsoft ao mesmo tempo.
- **Resultados Inteligentes**: Sugestões personalizadas com base no contexto do usuário.
- **Segurança**: Exibe apenas o que o usuário tem permissão para acessar.

Esse recurso é útil especialmente em ambientes corporativos, onde o volume de informação é grande e distribuído entre vários serviços.

## Azure Storage

O **Azure Storage** é o serviço de armazenamento em nuvem da Microsoft, utilizado para guardar arquivos, dados e backups com segurança e escalabilidade.

### Tipos de Armazenamento

- **Blob Storage**: Ideal para armazenar imagens, vídeos e arquivos grandes.
- **File Storage**: Compartilhamento de arquivos em rede, como um servidor de arquivos tradicional.
- **Table Storage**: Armazenamento de dados estruturados em formato NoSQL.
- **Queue Storage**: Filas de mensagens para comunicação entre aplicações.

Esse serviço é essencial para aplicações que precisam armazenar dados de forma confiável e com acesso global.

Nesta análise, utilizei apenas recursos básicos de cada serviço. Tanto o **Microsoft Search** quanto o **Azure Storage** oferecem muitas outras funcionalidades que podem ser exploradas em projetos mais avançados.
