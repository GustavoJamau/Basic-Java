# Uso de Máquina Virtual e Banco de Dados SQL no Microsoft Azure

Explorei dois serviços essenciais da plataforma Microsoft Azure: a **Máquina Virtual (VM)** e o **Banco de Dados SQL**. O objetivo foi entender como esses serviços funcionam na prática e como podem ser utilizados juntos no desenvolvimento e hospedagem de aplicações.

## 💻 Máquina Virtual (VM) no Azure

A Máquina Virtual permite criar um servidor virtual com controle total sobre o sistema operacional, sendo ideal para rodar aplicações, serviços e simular ambientes de produção.

### Funcionalidades:
- Execução remota de programas
- Configuração personalizada
- Acesso por RDP ou SSH
- Escalabilidade conforme a demanda

## 🗄️ Banco de Dados SQL no Azure

O Banco de Dados SQL é um serviço gerenciado para armazenar dados de forma segura e confiável, baseado no SQL Server.

### Funcionalidades:
- Alta disponibilidade e backups automáticos
- Escalabilidade flexível
- Segurança integrada
- Ideal para aplicações web e APIs

## 🔗 Integração

A aplicação hospedada na VM se conecta ao Banco de Dados SQL via string de conexão, simulando um ambiente real de produção em nuvem.

## ✅ Considerações Finais

Esta atividade foi realizada como parte de um desafio prático da **DIO (Digital Innovation One)**, com o objetivo de aplicar conhecimentos em computação em nuvem usando o Microsoft Azure.
