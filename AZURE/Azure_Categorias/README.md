
# 🌐 Serviços do Azure por Categoria

## 🔧 Computação
Serviços para executar aplicativos e cargas de trabalho.

- **Máquinas Virtuais (VMs)** – Infraestrutura como serviço (IaaS).
- **App Services** – Hospedagem de aplicativos web (PaaS).
- **Azure Kubernetes Service (AKS)** – Orquestração de contêineres.
- **Functions** – Computação serverless baseada em eventos.
- **Batch** – Processamento paralelo em larga escala.

## 🗂️ Armazenamento
Serviços para armazenar dados de diferentes tipos.

- **Blob Storage** – Armazenamento de objetos (imagens, vídeos, backups).
- **File Storage** – Compartilhamento de arquivos com protocolo SMB.
- **Queue Storage** – Filas para comunicação assíncrona entre aplicativos.
- **Table Storage** – Armazenamento NoSQL rápido e flexível.

## 🧠 Inteligência Artificial e Machine Learning
Serviços para criação, treinamento e implementação de modelos de IA.

- **Azure Machine Learning** – Treinamento e deploy de modelos.
- **Cognitive Services** – APIs pré-treinadas para visão, fala, linguagem e decisão.
- **Bot Services** – Criação e gerenciamento de bots inteligentes.

## 🛢️ Banco de Dados
Serviços de banco de dados gerenciados.

- **Azure SQL Database** – Banco de dados relacional baseado em SQL Server.
- **Cosmos DB** – Banco de dados NoSQL globalmente distribuído.
- **Azure Database for MySQL/PostgreSQL** – Serviços gerenciados de bancos open-source.

## 🔗 Rede
Serviços para conectividade, segurança e entrega de conteúdo.

- **Virtual Network (VNet)** – Redes privadas no Azure.
- **Application Gateway** – Balanceador de carga com WAF.
- **Azure DNS** – Gerenciamento de domínios DNS.
- **CDN** – Rede de entrega de conteúdo global.

## 🔐 Segurança e Identidade
Serviços para proteger dados e controlar o acesso.

- **Azure Active Directory (AAD)** – Gerenciamento de identidade e autenticação.
- **Key Vault** – Armazenamento seguro de chaves, segredos e certificados.
- **Security Center** – Monitoramento de segurança em tempo real.

## 📊 Monitoramento e Gerenciamento
Ferramentas para acompanhar e gerenciar recursos.

- **Azure Monitor** – Coleta e análise de métricas e logs.
- **Log Analytics** – Consulta e análise de dados operacionais.
- **Azure Automation** – Automação de tarefas de gerenciamento.

## 🔄 Integração
Serviços para conectar sistemas e dados.

- **Logic Apps** – Integração de sistemas via fluxos de trabalho automatizados.
- **Service Bus** – Mensageria corporativa.
- **Event Grid** – Roteamento de eventos em tempo real.

## 🌍 DevOps
Ferramentas para automação de pipelines e infraestrutura como código.

- **Azure DevOps Services** – CI/CD, repositórios Git e boards.
- **Azure Pipelines** – Automação de build e deploy.
- **Terraform no Azure** – Infraestrutura como código com Terraform.

---

## 🎨 Configurações Básicas

Estas configurações ajudam a personalizar a experiência no Azure Portal:

- **Tema de Cor**: Vá em "Configurações" > "Aparência" para alterar o tema (Claro, Escuro, Contraste).
- **Idioma**: Pode ser alterado nas preferências do usuário.
- **Painéis Personalizados**: Crie dashboards com recursos e métricas favoritas.
- **Notificações**: Configure alertas e notificações para recursos críticos.
- **Atalhos de Navegação**: Fixe serviços usados frequentemente no menu lateral.
