# ✅ Pré-requisitos

Para rodar o projeto com Maven sem instalar:

- Ter o **Java JDK** instalado (JDK 17 ou superior recomendado)
- Ter o **Apache Maven** apenas baixado (exemplo:  
  `C:\Users\Usuario1\Downloads\Maven\apache-maven-3.9.9`)
- Ter um projeto com o arquivo `pom.xml` (ex: `spring-boot-strategy-pattern`)

# 🧪 Códigos do Terminal Utilizados

## Acessar o diretório do projeto:

cd C:\Users\Usuario1\Documents\Projetos\Basic-Java\Spring-Java\spring-boot-strategy-pattern

# Rodar o projeto usando Maven baixado (sem instalar):

C:\Users\Usuario1\Downloads\Maven\apache-maven-3.9.9\bin\mvn.cmd spring-boot:run

# (Opcional) Criar um arquivo .bat para facilitar:

@echo off
cd C:\Users\Usuario1\Documents\Projetos\Basic-Java\Spring-Java\spring-boot-strategy-pattern
C:\Users\Usuario1\Downloads\Maven\apache-maven-3.9.9\bin\mvn.cmd spring-boot:run
pause
